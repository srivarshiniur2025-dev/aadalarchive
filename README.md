# Aadal Archive

**Where movement becomes memory.**

A premium visual platform and creative workspace for dancers — beginning with Bharatanatyam. Inspiration feed, collections, event albums, dance videos, and artistic profiles in one theatrical archive.

> From inspiration to rehearsal to performance, every movement deserves a place.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Lucide icons + custom dance icons
- Mock demo data (no backend yet)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## MVP surfaces

| Route | Purpose |
|-------|---------|
| `/` | Cinematic landing |
| `/signup` `/login` `/onboarding` | Auth + simple onboarding |
| `/discover` | Home inspiration feed |
| `/explore` | Search + filters |
| `/boards` | Collections (saved ideas) |
| `/albums` | Event / stage memories |
| `/choreography` | Dance videos |
| `/studio` | Practice space |
| `/capture` | Record practice |
| `/create` | Create collection, album, or video |
| `/profile` | Dance journey |
| `/notifications` | Gentle updates |
| `/settings` | Privacy and account |

## Design language

Deep charcoal, temple maroon, vermilion, antique gold, warm ivory, and brass — with kolam geometry, salangai-inspired loaders, temple arches, and curtain-inspired motion. Reduced-motion preferences are respected.

Copy stays simple and friendly while the look and motion feel like classical dance.

## Note on content

Demo media uses Unsplash imagery as placeholders. Production should use dancer-owned photography with full credit fields. Dance video uploads never imply ownership transfer from a teacher or lineage.
